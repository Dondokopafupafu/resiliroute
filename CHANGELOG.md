- Preserved the stable checkpoint and separate engine, evidence, UI and documentation commits in the local development-history backup. This public repository starts from the reviewed version 3.0 snapshot.

The advanced LLM brief, physical secondary-failure simulation, sensitivity sweep, temporary-link/capacity interventions and global robust optimization were intentionally deferred. Existing local/optional cloud AI briefs remain available.

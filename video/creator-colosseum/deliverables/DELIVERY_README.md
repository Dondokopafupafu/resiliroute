# ResiliRoute 提出用動画セット

完成動画は **4分54秒**、1920×1080・30fps・H.264/AACです。英語ナレーション、日本語・英語の二段字幕、オリジナルの薄いBGMを含みます。

## 提出に使うファイル

- `final-creator-colosseum-resiliroute.mp4`：完成動画。動画サイトへアップロードして提出フォームにリンクを記載してください。
- `THUMBNAIL.png`：1920×1080のサムネイル。実際の岡山ネットワーク画面を使用しています。
- `subtitles-en.srt` / `subtitles-ja.srt`：別ファイルの字幕。MP4にも両言語を焼き込んであります。
- `narration-en.txt` / `VIDEO_SCRIPT.md`：全文ナレーション、タイムコード、撮影対象、字幕、編集指示。
- `VIDEO_QA.json` / `PLAYBACK_QA.json`：完成動画の検査結果。
- `CONTACT_SHEET.png`：主要場面を一覧で確認できる画像。

## 内容と正確性

実際のアプリ操作が255秒、全体の約87%です。そのうち243秒がReal City Lab、12秒がHarbor Cityです。

岡山の実道路・病院をOpenStreetMapから取得し、相生橋の閉鎖、病院へのモデル移動時間の4.4→7.2分への変化、交通需要の再配分、追加閉鎖後の独立した復旧比較を収録しています。数値は共有シミュレーションエンジンと実際のUIで照合しました。道路・施設は実在データですが、交通需要・容量はモデル推定です。

収録した説明機能はローカルの数値分析です。任意のサーバーLLM連携は別に存在し、動画では実際の有料API呼び出しを装っていません。教育向け・専門分析向け・組織向けの事業モデルは将来案であり、既存契約や利用実績の主張ではありません。以前のImpactHack版とAI開発支援の使用も画面に明記しています。

このセットを作る処理ではGitHubへの変更公開、動画サイトへのアップロード、コンテストへの送信は行っていません。動画のGitHubリンクは既存リポジトリです。提出前に、最新のReal City Labコードが閲覧できる状態にしてリンクと一致させてください。

## 検査

アプリは63件の単体テスト、42件のデスクトップ・モバイルブラウザテスト、lint、format、型チェック、production buildを通過しました。動画は8,820フレームをデコードし、映像エラーなし、294秒、30fpsを確認しました。Chromiumで三つの主要場面を再生し、検査区間のドロップフレームは0でした。BGMはナレーションより約19dB低くしています。
